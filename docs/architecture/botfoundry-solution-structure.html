O que Executar

Sequência para montar o esqueleto do zero com a CLI do .NET.

1
Criar a solution
dotnet new sln -n BotFoundry.Telegram
2
Criar os 5 projetos classlib / xunit
dotnet new classlib -n BotFoundry.Telegram.Abstractions -o src/BotFoundry.Telegram.Abstractions
dotnet new classlib -n BotFoundry.Telegram.Core -o src/BotFoundry.Telegram.Core
dotnet new classlib -n BotFoundry.Telegram -o src/BotFoundry.Telegram
dotnet new xunit -n BotFoundry.Telegram.Core.Tests -o tests/BotFoundry.Telegram.Core.Tests
dotnet new xunit -n BotFoundry.Telegram.Integration.Tests -o tests/BotFoundry.Telegram.Integration.Tests
3
Adicionar projetos à solution
dotnet sln add src/**/*.csproj tests/**/*.csproj
4
Adicionar referências entre projetos
Conforme o diagrama de dependências acima — usando dotnet add reference
5
Adicionar pacotes NuGet
Conforme a tabela de cada projeto acima — usando dotnet add package
6
Remover arquivos gerados automaticamente
Deletar os Class1.cs e UnitTest1.cs gerados pelo template — a solution deve compilar vazia.
7
Validar com dotnet build
A solution deve compilar sem erros e sem warnings. dotnet test deve passar (zero testes é OK neste estágio).
